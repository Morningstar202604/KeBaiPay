# KeBaiPay 故障排查手册

> 本手册覆盖 KeBaiPay v0.3.5（合规聚合模式）在部署、认证、收单、商户接入、对账、风控等环节的高频问题。
> 所有命令均假设当前目录为项目根目录。

---

## 1. 部署与启动

| 症状 | 排查 |
|---|---|
| 服务起不来，数据库连接失败 | 检查 `DATABASE_URL`、PostgreSQL 是否启动、迁移是否执行（`npx prisma migrate deploy`） |
| Redis 连接失败 | 检查 `REDIS_URL`、Redis 是否启动；收单并发锁依赖 Redis |
| 端口被占用 | 修改 `.env` 中 `PORT` 或停掉占用进程 |
| Swagger 404 | 仅开发环境挂载（`NODE_ENV !== production`） |

---

## 2. 认证

| 症状 | 排查 |
|---|---|
| 登录提示"账号已被锁定" | 连续输错 5 次锁定 15 分钟，等待或管理员解锁 |
| JWT 解码失败 | 检查 `JWT_USER_SECRET` / `JWT_ADMIN_SECRET` 是否与签发时一致 |
| 开放 API 401 KB401 | 检查 `X-App-Id` / `X-Timestamp` / `X-Nonce` / `X-Signature`；服务器时钟差超 5 分钟会拒；签名算法为 `HMAC-SHA256(SHA256_RAW(appSecret), method\npath\nrawBody\ntimestamp\nnonce\nappId)`（HMAC 密钥是 appSecret 的 32 字节原始摘要，不是明文 appSecret，也不是 hex 字符串） |
| 开放 API 403 KB717 | 应用被禁用，联系管理员在门户启用 |

---

## 3. 收单与渠道回调

### 3.1 用户已付款但订单仍 PENDING

1. 查渠道后台：用户是否真的支付成功
2. 查平台日志：是否收到渠道回调，验签是否通过
3. 若回调丢失：平台定时任务 15 分钟内会主动查渠道补单；也可在商户门户手动重查
4. 若金额不符：fail-closed 拒绝确认，查渠道订单金额与下单金额是否一致

### 3.2 渠道回调一直失败

1. 确认 `CHANNEL_NOTIFY_URL` 为公网可达 HTTPS 地址
2. 检查回调验签逻辑：伪造回调必须返回 400
3. 平台按指数退避重试（最多 8 次）；超过则告警
4. 检查是否被 WAF / 防火墙拦截

### 3.3 退款未到账

1. 查平台退款单状态（`GET /open-api/v1/orders/:orderNo`）
2. 查渠道退款接口返回
3. 退款原路返回持牌渠道账户，时效由渠道决定（通常 1-3 工作日）
4. 平台不经手退款资金

---

## 4. 对账

| 症状 | 排查 |
|---|---|
| 对账差异 > 0 | 进入 `/admin/reconciliation/reports/:date` 查看差异明细；常见原因为渠道账单延迟、回调丢失、金额不符 |
| 渠道账单拉取失败 | 检查渠道凭据、网络出口白名单、渠道账单接口是否限流 |
| CSV 导出乱码 | 用 Excel 打开时选 UTF-8；或用 pandas / `iconv` 转码 |

---

## 5. 商户接入

| 症状 | 排查 |
|---|---|
| 商户入驻一直 PENDING | 管理员在 `/admin/merchants` 审核 |
| appSecret 泄露 | 门户「应用管理」→「重新生成密钥」，旧密钥立即失效 |
| 收单回调没收到 | 检查商户配置的 `notifyUrl` 是否公网可达、是否返回 200 |

---

## 6. AI 智能体

| 症状 | 排查 |
|---|---|
| AI 回复是模板 | 未配置 `LLM_PROVIDER` / `LLM_API_KEY`（mock 模式） |
| 智能体调用工具 403 | 检查作用域（scope）、单笔/日限额、是否需要二次确认 |
| 审计链校验失败 | `audit` 调度任务会报；联系管理员按哈希链定位被篡改的日志 |

---

## 7. 常见错误码

| code | 含义 | 处理 |
|---|---|---|
| KB401 | 签名/认证失败 | 检查签名、token |
| KB603 | 订单不存在 | 检查 orderNo |
| KB713 | 订单不可退 | 订单非 PAID 状态 |
| KB715 | 退款金额无效 | 退款金额 > 可退金额 |
| KB717 | 应用已禁用 | 联系管理员 |
