## 一、快速开始

| 端 | 地址（默认端口 3001） | 使用者 |
|---|---|---|
| 用户端 H5 | `http://<你的域名>:3001/h5/` | 普通用户 |
| 商户门户 | `http://<你的域名>:3001/portal/` | 商户/店铺 |
| 管理后台 | `http://<你的域名>:3001/admin/` | 平台运营 |
| 演示 SPA | `http://<你的域名>:3001/` | 快速体验 |

**首次登录**：用 `docs/HANDOVER.md` 中的测试账号或企业自行创建的账号。
**界面语言**：简体中文。**推荐浏览器**：Chrome / Edge / Safari 最新版。

## 二、用户端 H5（钱包）

### 2.1 登录页 `#/login`

![H5 登录](demo/screenshots/h5-login.png)

| 元素 | 说明 |
|---|---|
| 手机号/邮箱 输入框 | 注册时使用的手机号或邮箱 |
| 密码 输入框 | 登录密码（区别于支付密码） |
| 「登 录」按钮 | 校验通过后进入钱包首页；连续错误 5 次锁定 15 分钟 |
| 「立即注册」链接 | 跳转注册页 |

> 注意：**登录密码**用于登录，**支付密码**（6 位数字）用于转账/提现等资金确认，两者独立。

### 2.2 注册页 `#/register`

| 元素 | 说明 |
|---|---|
| 昵称 | 展示用名称，账单与转账对方可见 |
| 手机号 + 密码 | 手机号唯一；密码 ≥ 8 位含字母数字 |
| 「注 册」按钮 | 成功后自动登录并引导实名认证 |

### 2.3 钱包首页 `#/home`

![H5 首页](demo/screenshots/h5-home.png)

| 元素 | 说明 |
|---|---|
| 账户总余额卡片 | 展示总余额/可用余额/冻结余额（单位：元）；冻结金额 = 提现审核中或担保交易中的资金 |
| 「充值」按钮 | 打开充值页，通过支付渠道为钱包充值 |
| 「转账」按钮 | 打开转账页，向其他实名用户转出 |
| 「提现」按钮 | 打开提现页，申请将余额提现至银行卡 |
| 「红包」按钮 | 打开发红包页 |
| 「最近账单」卡片 | 展示最近收支记录，点击可进入账单页 |
| 底部导航（钱包/账单/红包/AI助手/收银台） | 五大功能区切换 |

### 2.4 充值 `#/recharge`

![H5 充值](demo/screenshots/h5-recharge.png)

| 元素 | 说明 |
|---|---|
| 金额输入框 | 单位：元，支持两位小数 |
| 支付密码输入框 | 6 位支付密码 |
| 「确认充值」按钮 | 创建充值订单并跳转支付渠道（默认 mock 渠道一键完成）；到账由渠道回调确认 |
| 幂等键 | 系统自动生成；网络超时重试不会重复扣款 |

### 2.5 转账 `#/transfer`

| 元素 | 说明 |
|---|---|
| 对方用户输入 | 对方手机号（转账双方均须完成实名认证） |
| 金额输入框 | 单笔/单日限额见管理后台系统配置 |
| 备注 | 可选，对方账单可见 |
| 支付密码 | 资金确认 |
| 「确认转账」按钮 | 原子扣款 + 实时到账对方可用余额 |

### 2.6 提现 `#/withdraw`

| 元素 | 说明 |
|---|---|
| 金额输入框 | 提现金额 = 到账金额 + 手续费；须 ≤ 可用余额 |
| 银行卡信息 | 按管理后台配置的提现渠道要求填写 |
| 支付密码 + 「申请提现」按钮 | 提交后资金进入冻结状态，待管理员审核 |

> 提现审核通过后由渠道代付到卡；被驳回时冻结金额自动退回可用余额。

### 2.7 红包 `#/redpacket`

![H5 红包](demo/screenshots/h5-redpacket.png)

| 元素 | 说明 |
|---|---|
| 发红包：金额 + 数量 + 类型 | 普通红包（平均）/拼手气（二倍均值法随机）；专属红包仅指定人可领；口令红包需输入口令 |
| 「塞钱进红包」按钮 | 金额一次性从余额扣除并冻结，24 小时未领完自动退回 |
| 领红包：口令输入（口令红包） | 校验通过即领取，金额实时入账 |
| 红包列表 | 已发/已收两个标签页 |

### 2.8 账单 `#/bills`

![H5 账单](demo/screenshots/h5-bills.png)

| 元素 | 说明 |
|---|---|
| 「全部 / 收入 / 支出」筛选 | 按方向过滤账单 |
| 账单行 | 类型 + 收/支标记 + 时间 + 对方 + 金额（收入 +、支出 -） |

### 2.9 收银台 `#/cashier`

![H5 收银台](demo/screenshots/h5-cashier.png)

| 元素 | 说明 |
|---|---|
| 创建订单表单 | 商户下单后由用户在此支付；或自行创建收款订单 |
| 「支付」按钮 | 校验支付密码后从余额扣款，商户实时收到回调通知 |

### 2.10 实名认证 `#/kyc`

| 元素 | 说明 |
|---|---|
| 姓名 + 身份证号 | 身份证号 AES-256 加密存储；一个证件号只能认证一个账号 |
| 支付密码（6 位） | 首次设置支付密码；管理员审核通过后生效 |
| 「提交认证」按钮 | 提交后进入 PENDING；开启 `SANDBOX_AUTO_APPROVE` 的沙箱环境自动通过 |

### 2.11 AI 助手 `#/agent`

![H5 AI 助手](demo/screenshots/h5-agent.png)

| 元素 | 说明 |
|---|---|
| 智能体卡片列表 | 显示管理后台创建的智能体（部署自带「科佰钱包管家」） |
| 「连接智能体」按钮 | 授权该智能体访问你的钱包（scope 授权）并建立会话 |
| 对话输入框 | 直接说需求，如"查一下余额""最近账单" |
| 「发送」按钮 | 发送消息；AI 调用工具返回结果 |
| 「断开」按钮 | 结束会话 |
| 资金类操作 | AI 提议转账等操作时，会弹出**二次确认**，你确认后才会执行；可拒绝 |
| 安全边界 | 单笔/单日限额由管理后台配置；可随时在「断开」撤销授权 |

> AI 回复质量取决于 LLM 配置：默认 `LLM_PROVIDER=mock` 为模板回复；在 `.env` 配置真实 LLM Key 后升级为智能对话。

## 三、商户门户 Portal

### 3.1 登录/注册 `#/login`

![门户登录](demo/screenshots/portal-login.png)

商户账号与个人账号体系独立。「立即入驻」进入商户注册流程：**实名认证 → 商户入驻申请 → 管理员审核**。

### 3.2 数据看板 `#/dashboard`

![门户看板](demo/screenshots/portal-dashboard.png)

展示商户维度的交易总额、订单数、收款码收款等关键指标。

### 3.3 应用管理 `#/apps`

![门户应用](demo/screenshots/portal-apps.png)

| 元素 | 说明 |
|---|---|
| 「创建应用」按钮 | 填写应用名称与回调地址；**appSecret 仅创建时明文显示一次**，请立即保存 |
| appSecret 脱敏 | 列表中只显示脱敏摘要；泄露可使用「重新生成密钥」（同样只显示一次） |
| 回调地址要求 | http/https、禁止内网地址 |

### 3.4 收款码 `#/qrcodes`

![门户收款码](demo/screenshots/portal-qrcodes.png)

| 元素 | 说明 |
|---|---|
| 「创建收款码」 | 固定金额码 / 自定义金额码 |
| 二维码下载 | 供线下张贴；用户扫码进入收银台付款 |

### 3.5 订单管理 `#/orders`

![门户订单](demo/screenshots/portal-orders.png)

订单列表支持按状态筛选、查看回调通知状态（成功/失败/重试次数），未成功通知的订单可**手动重发回调**。

### 3.6 对账查询 `#/reconciliation`

![门户对账](demo/screenshots/portal-reconciliation.png)

按日期导出/查询商户订单与流水的对账明细，支持 CSV 导出。

## 四、管理后台 Admin

### 4.1 登录 `#/login`

![后台登录](demo/screenshots/admin-login.png)

账号由超级管理员创建；初始密码来自部署时 `ADMIN_DEFAULT_PASSWORD`，**首次登录后请立即在「管理员管理」中修改**。

### 4.2 数据概览 `#/dashboard`

![后台概览](demo/screenshots/admin-dashboard.png)

平台关键运营指标：用户总数、商户总数、今日订单、待处理提现、待审核商户。点击指标卡跳转对应页面处理。

### 4.3 用户管理 `#/users`

![后台用户](demo/screenshots/admin-users.png)

| 元素 | 说明 |
|---|---|
| 状态筛选 + 「查询」按钮 | 按账号状态过滤（全部状态时不传该参数） |
| 「冻结 / 解冻」按钮 | 冻结后用户禁止登录与交易；操作写入审计哈希链 |
| 分页器 | 大数据量分页浏览 |

### 4.4 商户管理 `#/merchants`

![后台商户](demo/screenshots/admin-merchants.png)

「通过 / 驳回」商户入驻申请（驳回需填原因）；配置费率与单日限额。费率影响商户收款手续费。

### 4.5 实名审核 `#/identities`

| 元素 | 说明 |
|---|---|
| 待审核列表 | 展示用户提交的姓名 + 脱敏证件号 |
| 「通过」按钮 | 用户实名状态置 VERIFIED，支付密码生效 |
| 「驳回」按钮 | 需填写驳回原因，用户可修改后重新提交 |

### 4.6 渠道配置 `#/channels`

| 元素 | 说明 |
|---|---|
| 「新增渠道」按钮 | 填写编码/名称/类型/优先级与凭据 JSON |
| 「编辑」按钮 | 修改渠道凭据；**凭据 AES-256-GCM 加密存储**，列表仅显示脱敏摘要 |
| 「测试」按钮 | 检测渠道可用性 |
| 「删除」按钮 | 删除渠道（有订单关联时请谨慎） |
| 热同步 | 保存后自动同步到连接器运行时，无需重启服务 |

### 4.7 提现审核 `#/withdrawals`

![后台提现审核](demo/screenshots/admin-review-withdrawals.png)

| 元素 | 说明 |
|---|---|
| 待审核列表 | 展示提现单号/用户/金额/申请时间 |
| 「通过」按钮 | 冻结金额转渠道代付；代付结果由渠道回调更新 |
| 「拒绝」按钮 | 冻结金额自动退回用户可用余额 |

### 4.8 支付订单 `#/orders`

![后台订单](demo/screenshots/admin-orders.png)

全平台收银台订单列表，支持按状态筛选，可查看回调通知状态并手动重发。

### 4.9 财务总览 `#/finance`

![后台财务](demo/screenshots/admin-finance.png)

总交易额/总收入/总支出/手续费/净收入/总资产 + 订单状态分布。数据来自每日快照与实时聚合。

### 4.10 风控事件 `#/risk`

![后台风控](demo/screenshots/admin-risk.png)

大额交易、频繁交易、异常登录等风控事件列表；按级别（LOW/MEDIUM/HIGH）与状态筛选，支持人工处置。

### 4.11 智能体管理 `#/agents`

![后台智能体](demo/screenshots/admin-agents.png)

| 元素 | 说明 |
|---|---|
| 「新建智能体」按钮 | 名称/场景（wallet 钱包管家 / merchant 店长助理 / risk 风控审计官）/作用域/描述 |
| 作用域配置 | 决定 AI 可调用哪些工具（wallet:read、wallet:write:transfer 等） |
| 密钥 | 创建时明文返回一次，仅存哈希 |

> AI 对话需要配置 LLM：`.env` 中 `LLM_PROVIDER`（openai/deepseek 等）+ `LLM_API_KEY`；未配置时自动降级为 mock 模板回复。

## 五、常见问题 FAQ

| 问题 | 处理 |
|---|---|
| 登录提示"账号已被锁定" | 连续输错 5 次锁定 15 分钟，稍后自动解锁 |
| 支付密码与登录密码的区别 | 登录密码进系统；支付密码（6 位数字）确认资金操作，错 5 次锁 15 分钟 |
| 提现后钱去哪了 | 提交后进入冻结 → 管理员审核 → 渠道代付；驳回自动退回 |
| 充值未到账 | 渠道回调延迟；超过 15 分钟系统自动告警，联系管理员核对渠道订单 |
| AI 助手回复是模板 | 未配置 LLM Key（mock 模式），按 HANDOVER 配置 `LLM_PROVIDER`/`LLM_API_KEY` |
| 转账提示需要实名 | 转账双方均须完成实名认证（H5 → 实名认证页提交） |
| 商户 appSecret 丢了 | 门户「应用管理」→「重新生成密钥」，旧密钥立即失效 |
| 页面金额单位 | 所有界面展示均为「元」；数据库存储为「分」 |
