## 一、快速开始

| 端 | 地址（默认端口 3001） | 使用者 |
|---|---|---|
| 用户端 H5 | `http://<你的域名>:3001/h5/` | 付款方用户 |
| 商户门户 | `http://<你的域名>:3001/portal/` | 商户/店铺 |
| 管理后台 | `http://<你的域名>:3001/admin/` | 平台运营 |
| 演示 SPA | `http://<你的域名>:3001/` | 快速体验 |

**首次登录**：使用部署文档提供的测试账号或企业自行创建的账号。
**界面语言**：简体中文。**推荐浏览器**：Chrome / Edge / Safari 最新版。

## 二、用户端 H5

### 2.1 登录页 `#/login`

![H5 登录](../demo/screenshots/h5-login.png)

| 元素 | 说明 |
|---|---|
| 手机号/邮箱 输入框 | 注册时使用的手机号或邮箱 |
| 密码 输入框 | 登录密码 |
| 「登 录」按钮 | 校验通过后进入首页；连续错误 5 次锁定 15 分钟 |
| 「立即注册」链接 | 跳转注册页 |

### 2.2 注册页 `#/register`

| 元素 | 说明 |
|---|---|
| 昵称 | 展示用名称 |
| 手机号 + 密码 | 手机号唯一；密码 ≥ 8 位含字母数字 |
| 「注 册」按钮 | 成功后自动登录并引导实名认证 |

### 2.3 首页 `#/home`

| 元素 | 说明 |
|---|---|
| 收单概览卡片 | 展示用户作为付款方的近期收单订单概览 |
| 「账单」入口 | 进入账单页查看历史支付记录 |
| 底部导航（首页/账单/AI助手/收银台） | 主要功能区切换 |

### 2.4 账单 `#/bills`

![H5 账单](../demo/screenshots/h5-bills.png)

| 元素 | 说明 |
|---|---|
| 状态筛选 | 按订单状态过滤（已支付/已退款/已关闭） |
| 账单行 | 商户名称 + 订单号 + 时间 + 金额（元） |

> 账单仅展示通过本平台发起的收单订单与退款记录；平台不持有任何资金，无余额概念。

### 2.5 收银台 `#/cashier`

| 元素 | 说明 |
|---|---|
| 订单详情 | 商户订单号、金额、收款商户 |
| 「选择渠道支付」按钮 | 跳转所选持牌渠道（微信/支付宝/mock）完成支付 |
| 支付结果 | 渠道回调后自动更新订单状态；未收到回调时由定时任务主动查询渠道补单 |

### 2.6 实名认证 `#/kyc`

| 元素 | 说明 |
|---|---|
| 姓名 + 身份证号 | 身份证号 AES-256 加密存储；一个证件号只能认证一个账号 |
| 支付密码（6 位） | 首次设置支付密码；管理员审核通过后生效 |
| 「提交认证」按钮 | 提交后进入 PENDING；开启 `SANDBOX_AUTO_APPROVE` 的沙箱环境自动通过 |

### 2.7 AI 助手 `#/agent`

![H5 AI 助手](../demo/screenshots/h5-agent.png)

| 元素 | 说明 |
|---|---|
| 智能体卡片列表 | 显示管理后台创建的智能体 |
| 「连接智能体」按钮 | 授权该智能体访问你的收单数据（scope 授权）并建立会话 |
| 对话输入框 | 直接说需求，如"最近账单""某订单状态" |
| 「发送」按钮 | 发送消息；AI 调用工具返回结果 |
| 「断开」按钮 | 结束会话并撤销授权 |
| 二次确认 | AI 提议需要确认的操作时弹出确认框，你确认后才会执行；可拒绝 |
| 安全边界 | 单笔/单日限额由管理后台配置 |

> AI 回复质量取决于 LLM 配置：默认 `LLM_PROVIDER=mock` 为模板回复；在 `.env` 配置真实 LLM Key 后升级为智能对话。

## 三、商户门户 Portal

### 3.1 登录/注册 `#/login`

![门户登录](../demo/screenshots/portal-login.png)

商户账号与个人账号体系独立。「立即入驻」进入商户注册流程：**实名认证 → 商户入驻申请 → 管理员审核**。

### 3.2 数据看板 `#/dashboard`

![门户看板](../demo/screenshots/portal-dashboard.png)

展示商户维度的收单总额、订单数、收款码收款、退款等关键指标。

### 3.3 应用管理 `#/apps`

![门户应用](../demo/screenshots/portal-apps.png)

| 元素 | 说明 |
|---|---|
| 「创建应用」按钮 | 填写应用名称与回调地址；**appSecret 仅创建时明文显示一次**，请立即保存 |
| appSecret 脱敏 | 列表中只显示脱敏摘要；泄露可使用「重新生成密钥」（同样只显示一次） |
| 回调地址要求 | http/https、禁止内网地址 |

### 3.4 收款码 `#/qrcodes`

![门户收款码](../demo/screenshots/portal-qrcodes.png)

| 元素 | 说明 |
|---|---|
| 「创建收款码」 | 固定金额码 / 自定义金额码 |
| 二维码下载 | 供线下张贴；用户扫码进入收银台付款 |

### 3.5 订单管理 `#/orders`

![门户订单](../demo/screenshots/portal-orders.png)

收单订单列表支持按状态筛选、查看回调通知状态（成功/失败/重试次数），未成功通知的订单可**手动重发回调**。

### 3.6 对账查询 `#/reconciliation`

![门户对账](../demo/screenshots/portal-reconciliation.png)

按日期导出/查询商户收单订单与渠道账单的对账明细，支持 CSV 导出。

## 四、管理后台 Admin

### 4.1 登录 `#/login`

![后台登录](../demo/screenshots/admin-login.png)

账号由超级管理员创建；初始密码来自部署时 `ADMIN_DEFAULT_PASSWORD`，**首次登录后请立即在「管理员管理」中修改**。

### 4.2 数据概览 `#/dashboard`

平台关键运营指标：用户总数、商户总数、今日收单订单、待审核商户、待实名审核。点击指标卡跳转对应页面处理。

### 4.3 用户管理 `#/users`

![后台用户](../demo/screenshots/admin-users.png)

| 元素 | 说明 |
|---|---|
| 状态筛选 + 「查询」按钮 | 按账号状态过滤 |
| 「冻结 / 解冻」按钮 | 冻结后用户禁止登录与发起收单；操作写入审计哈希链 |
| 分页器 | 大数据量分页浏览 |

### 4.4 商户管理 `#/merchants`

![后台商户](../demo/screenshots/admin-merchants.png)

「通过 / 驳回」商户入驻申请（驳回需填原因）；配置收单费率与单日限额。费率影响商户手续费收入。

### 4.5 实名审核 `#/identities`

| 元素 | 说明 |
|---|---|
| 待审核列表 | 展示用户提交的姓名 + 脱敏证件号 |
| 「通过」按钮 | 用户实名状态置 VERIFIED |
| 「驳回」按钮 | 需填写驳回原因，用户可修改后重新提交 |

### 4.6 渠道配置 `#/channels`

| 元素 | 说明 |
|---|---|
| 「新增渠道」按钮 | 填写编码/名称/优先级与凭据 JSON |
| 「编辑」按钮 | 修改渠道凭据；**凭据 AES-256-GCM 加密存储**，列表仅显示脱敏摘要 |
| 「测试」按钮 | 检测渠道可用性 |
| 「删除」按钮 | 删除渠道（有订单关联时请谨慎） |
| 热同步 | 保存后自动同步到连接器运行时，无需重启服务 |

### 4.7 支付订单 `#/orders`

![后台订单](../demo/screenshots/admin-orders.png)

全平台收单订单列表，支持按状态筛选，可查看回调通知状态并手动重发。

### 4.8 财务总览 `#/finance`

![后台财务](../demo/screenshots/admin-finance.png)

收单总额、手续费收入、商户结算明细、每日快照；数据来自每日快照与实时聚合。

### 4.9 风控事件 `#/risk`

![后台风控](../demo/screenshots/admin-risk.png)

大额交易、频繁交易、异常登录等风控事件列表；按级别（LOW/MEDIUM/HIGH）与状态筛选，支持人工处置。

### 4.10 智能体管理 `#/agents`

| 元素 | 说明 |
|---|---|
| 「新建智能体」按钮 | 名称/场景/作用域/描述 |
| 作用域配置 | 决定 AI 可调用哪些工具（收单查询、账单查询等） |
| 密钥 | 创建时明文返回一次，仅存哈希 |

> AI 对话需要配置 LLM：`.env` 中 `LLM_PROVIDER`（openai/deepseek 等）+ `LLM_API_KEY`；未配置时自动降级为 mock 模板回复。

## 五、常见问题 FAQ

| 问题 | 处理 |
|---|---|
| 登录提示"账号已被锁定" | 连续输错 5 次锁定 15 分钟，稍后自动解锁 |
| 支付密码与登录密码的区别 | 登录密码进系统；支付密码（6 位数字）确认收单/退款等操作，错 5 次锁 15 分钟 |
| 支付未到账 | 渠道回调延迟；超过 15 分钟系统自动查渠道补单，联系管理员核对渠道订单 |
| 退款去了哪里 | 退款原路返回付款方在持牌渠道的账户，平台不经手 |
| AI 助手回复是模板 | 未配置 LLM Key（mock 模式），按部署文档配置 `LLM_PROVIDER`/`LLM_API_KEY` |
| 商户 appSecret 丢了 | 门户「应用管理」→「重新生成密钥」，旧密钥立即失效 |
| 页面金额单位 | 所有界面展示均为「元」；数据库存储为「分」 |
| 平台能替我管钱吗 | 不能。本平台是合规聚合技术服务商，资金由持牌支付机构直接清算，平台不设余额、不设资金池 |
