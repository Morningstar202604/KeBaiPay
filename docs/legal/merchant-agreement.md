# KeBaiPay 商户服务协议

> 版本：V1.0 ｜ 生效日期：【2026 年 X 月 X 日】
> 甲方（服务提供方）：【企业全称】，以下简称"本平台"
> 乙方（入驻商户）：依平台流程完成入驻审核的主体

乙方向本平台申请开通商户服务，双方经协商一致，订立本协议。

---

## 一、服务内容

1. 本平台向乙方提供商户入驻、应用管理、收银台、收款码、开放 API（OpenAPI）交易接口、订单与对账查询、财务报表等技术服务；
2. 开放接口采用 **HMAC 签名认证**，乙方应依《SDK 指南》与《商户接入指南》完成接入并妥善保管 API 密钥；
3. 乙方理解并同意：本平台提供的是**技术系统与对账管理服务**，资金的实际收付、清结算依《合规声明》由持牌机构或银行通道完成。

## 二、入驻与资质

1. 乙方应提交真实、合法、有效的主体资质与经营信息（营业执照、法定代表人/经营者身份信息、行业经营许可等），并通过平台审核；
2. 乙方信息发生变更（含经营范围、主体变更、实际控制人变更）应在【10】日内告知本平台并更新；
3. 乙方不得以任何形式将商户账号、接口权限转让、出借给第三方使用。

## 三、交易与结算规则

1. **手续费**：本平台按签约费率收取交易服务费，费率以商户后台展示/双方约定为准；本平台调整费率将提前【30】日通知；
2. **结算**：交易资金依结算周期划入乙方指定结算账户；乙方应及时核对平台提供的对账文件，对账差异应在【T+7】日内提出；
3. **退款**：乙方向买家提供退款时，应通过平台退款接口或后台操作；退款资金从未结算款项或乙方结算账户中扣减；
4. **担保交易**：买家确认收货或超时自动确认后，对应货款方可入乙方可用余额；
5. **差错处理**：因渠道回调延迟、重复通知等造成的差错，依平台对账规则调整，重复入账部分平台有权冲正。

## 四、乙方行为规范

1. 乙方仅得将服务用于其**经审核的真实经营范围**内的交易，不得超范围经营；
2. 严禁利用本平台从事：洗钱、套现、二清（未经许可从事资金结算）、赌博、色情、诈骗、非法集资、侵权盗版、虚假交易等行为；
3. 禁止交易品类以《禁入行业清单》为准（附录 A），包括但不限于法律法规禁止或本平台风控政策限制的品类；
4. 乙方应保障其交易的**真实性、合法性**，留存交易凭证以备查验；本平台有权依风控规则要求乙方补充材料，或对可疑交易采取延迟结算、冻结、暂停服务等措施；
5. 乙方对其用户个人信息处理行为独立承担法律责任，并应与本平台各自履行个人信息处理者义务。

## 五、风控与处置

1. 本平台有权建立并调整风控规则（含限额、频率、名单类规则）以防范资金风险；
2. 出现下列情形之一的，本平台有权视情节采取限制功能、延迟结算、冻结资金、终止服务并上报监管/司法机关：
   - 触发风控规则且乙方无法合理解释；
   - 监管或有权机关要求；
   - 乙方违反本协议约定；
3. 冻结资金在风险排除后依规则解冻或按有权机关要求处理。

## 六、知识产权与数据

1. 本平台软件及文档的知识产权归权利人所有；乙方依本协议获得**非独占、不可转让的使用权**；
2. 乙方基于开放接口产生的订单与交易数据，本平台为履行服务、对账与监管义务之目的进行存储与处理；
3. 未经对方书面同意，任何一方不得向第三方披露对方的商业秘密。

## 七、责任与免责

1. 因乙方违规交易导致的处罚、退款、赔偿及监管责任由乙方承担；
2. 因本平台系统故障导致乙方无法正常使用的，本平台依服务等级承诺（SLA）承担相应责任，累计赔偿以乙方当期已支付服务费为上限；
3. 因不可抗力、渠道方原因、监管政策调整导致服务受限的，双方互不承担违约责任，但应互相配合减损。

## 八、期限与终止

1. 本协议自乙方入驻审核通过之日起生效，有效期【1 年】，期满自动续展；
2. 任一方可提前【30】日书面通知终止；终止后乙方应停止使用接口，双方完成最后一期对账与结算；为处理未完结交易，本平台有权保留必要的数据处理与结算功能至交易完结。

## 九、争议解决

本协议适用中华人民共和国法律。争议应先友好协商；协商不成的，提交【运营主体所在地有管辖权的人民法院 / 双方约定的仲裁机构】。
