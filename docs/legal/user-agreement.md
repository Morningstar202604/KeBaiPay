1. 您承诺以真实、准确、完整的信息注册，并依法律法规及本平台规则完成**实名认证**；实名信息变更时应及时更新。

3. 您应妥善保管登录密码、支付密码及验证码。**凡通过您的账户密码验证发起的操作，均视为您本人行为**，由此产生的损失由您自行承担（本平台有过错的除外）。

## 三、服务内容

本平台提供以下系统功能：

1. **账户服务**：余额查询、充值、账单查询；
2. **资金流转**：用户间转账、红包（普通、口令、专属、拼手气）；
3. **担保交易**：买卖双方通过平台担保完成付款、发货、确认收货、退款；
4. **提现服务**：将账户余额提取至您本人名下绑定的银行账户；
5. **商户与开放接口服务**：依另行签署的《商户服务协议》提供；
6. 本平台为**技术服务提供方**，资金的实际收付依托持牌支付机构或银行通道完成（见《合规声明》）。

## 五、资金规则

1. **充值**：充值资金通过合作支付渠道进入本平台合作托管账户体系；因渠道原因导致到账延迟的，本平台不承担渠道责任，但将协助查询。
2. **转账与红包**：资金一旦转出并到达对方账户，非经法定程序或对方同意不能单方撤销；转账前请核实对方身份。
3. **担保交易**：买家确认收货后货款划转给卖家；买家可依《退款与争议处理规则》在收货前申请退款。
4. **提现**：本平台依提现规则收取手续费（以页面展示为准）；提现至银行卡到账时间一般为【1-3 个工作日】，具体以渠道为准。
5. **限额**：账户可能存在单笔/单日/单月限额，具体以风控策略与监管要求为准。
6. **非活期存款**：您理解并同意，账户余额记录不构成存款，本平台不支付利息。
