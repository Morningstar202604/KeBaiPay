## 一、我们收集的信息

| 类别 | 具体信息 | 收集场景 |
|---|---|---|
| 账户信息 | 手机号/邮箱、昵称、登录密码（不可逆加密存储） | 注册登录 |
| 实名信息 | 姓名、身份证件号码（加密存储）、人脸/证件影像（如适用） | 实名认证 |
| 交易信息 | 充值、转账、红包、担保交易、提现记录及对应银行账户信息 | 使用资金功能 |
| 设备与日志信息 | IP 地址、设备型号、操作系统、访问时间、操作日志 | 保障安全、履行日志留存义务 |
| 客服信息 | 您与客服沟通时提供的内容 | 问题处理 |

我们**不收集**与服务无关的个人信息，不进行超出告知范围的处理。

## 二、处理目的与法律依据

1. **履行合同所必需**：创建与管理账户、提供充值/转账/红包/担保/提现功能、通知交易结果；
2. **履行法定义务所必需**：实名制核验、反洗钱与反恐怖融资监测、监管报送、司法协助；依据《反洗钱法》等要求，您的身份资料与交易记录将保存不少于 5 年；
3. **征得您同意**：客服回访、产品体验改进调研等可选场景；您可随时撤回同意；
4. **安全风控**：设备指纹、登录日志用于识别盗号、欺诈与异常交易，保障您的资金安全。

## 三、共享、委托与对外提供

1. **支付渠道与银行**：为完成充值、提现、代付，需向合作持牌机构提供必要交易信息；
2. **监管与司法**：依法律法规或有权机关要求提供的记录与信息；
3. 我们不会向任何第三方**出售**您的个人信息；委托处理个人信息的，将与受托方约定处理目的、期限、方式与保护措施并监督执行；
4. 除上述情形外，向第三方提供您的个人信息前，我们将另行征得您的单独同意。

## 四、存储与安全

1. **存储地点**：中华人民共和国境内；因业务确需跨境提供的，将依法履行评估与告知义务；
2. **存储期限**：为实现处理目的所必需的期限；交易与身份记录依反洗钱要求不少于 5 年；
3. **安全技术**：传输加密（TLS）、敏感字段加密存储、支付密码不可逆加密、数据库审计与操作日志哈希链防篡改、最小权限访问控制；
4. **应急响应**：发生或可能发生个人信息泄露时，我们将立即采取补救措施，并依《个保法》要求通知履行个人信息保护职责的部门和个人。

## 五、您的权利

您对您的个人信息享有下列权利，可通过【客服邮箱 / App 内入口】行使：

1. **查阅与复制**：您可在"个人中心"查看并导出账户与交易信息；
2. **更正与补充**：发现信息错误时可要求更正；
3. **删除**：符合法定情形时（如处理目的已实现、我们违法处理等），可要求删除；
4. **撤回同意**：撤回同意不影响撤回前基于同意的处理效力；
5. **注销**：您可申请注销账户；注销后我们将停止为您提供服务，并依法删除或匿名化处理您的个人信息（法律要求留存的除外）；
6. **解释说明**：有权要求我们对处理规则进行解释说明。

我们将在【15】个工作日内响应您的请求。若您对处理结果不满意，可向【网信部门 / 个人信息保护投诉渠道】投诉举报。

## 六、未成年人保护

本平台服务面向成年人。我们不会主动收集未成年人的个人信息；如您为未成年人，请在监护人陪同下阅读本政策并征得监护人同意后使用服务。
