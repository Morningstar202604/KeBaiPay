# 退款与争议处理规则

> 版本：V2.0 ｜ 生效日期：【2026 年 X 月 X 日】
> 运营主体：【企业全称】
> 模式说明：本平台为**聚合支付技术服务商**，退款均由持牌支付机构**原路退回**，
> 平台不经手资金，不设"平台余额/担保冻结/提现"概念。

本规则适用于本平台全部用户与商户，是《用户服务协议》《商户服务协议》的组成部分。

---

## 一、总则

1. 本规则所称"退款"，指收单订单因撤销、部分履行、商户申请等原因，由持牌支付机构将款项**原路退回**付款方原支付账户的行为；
2. 退款处理遵循"**谁收款、谁退回**"与"**原路退回**"原则；
3. 手续费处理：因商户原因退款的服务费不予减免；因平台/持牌机构原因退款的，相关费用按持牌机构规则处理。

## 二、收单订单退款

1. 退款由**商户**在商户后台或开放 API 发起，须满足：
   - 原订单状态为**已支付（PAID）**；
   - 退款金额不超过原订单金额减去已退累计金额；
2. 退款发起后，本平台转交持牌支付机构处理，处理结果以持牌机构返回为准：
   - 成功 → 订单标记为已退款（全额）或保持已支付（部分退款），`refundAmount` 累加；
   - 失败 → 订单状态不变，商户可重新发起；
3. 退款到账时间以持牌机构/发卡行为准（通常【1-7 个工作日】），本平台可协助查询进度。

## 三、交易争议处理

1. 因商品/服务质量产生的买卖争议，**优先由买卖双方协商解决**；协商不成的，可提交本平台争议处理（限平台可举证的范围：订单、支付、退款状态）；
2. 本平台为聚合技术服务商，**不参与买卖双方对交易标的的担保**；对商品质量、履约纠纷，本平台依法提供订单凭证等必要协助；
3. 涉嫌违法犯罪的争议（诈骗、盗用、洗钱等），本平台将依法向有权机关报告并配合调查，以有权机关的结论为最终处理依据。

## 四、争议处理流程

```
用户/商户提交争议 → 平台受理（1 个工作日内响应）
      ↓
双方举证（交易凭证、订单记录等，3 个工作日内）
      ↓
平台依规则作出处理决定 → 配合发起退款/提供证据
      ↓
对结果有异议 → 可申请复核一次 / 依协议约定诉讼或仲裁
```

1. 平台处理争议以系统记录（订单状态、退款记录）与双方提交的证据为依据；
2. 涉嫌违法犯罪（诈骗、盗窃、洗钱等）的争议，平台将依法配合有权机关冻结涉案订单相关资金（由持牌机构执行）并移交处理。
